   - Alternatively, open the file in the built-in AI Studio code canvas / HTML preview window to test all interactive features (Satellite rooftop sizer, EMI calculator, 9 product varieties, WhatsApp chat buttons).

2. **Option B: One-Click Launch via GitHub Pages (Live on solviroenergy.in)**
   - Create a repository named `solviroenergy` on GitHub.
   - Upload the extracted files from this zip (`index.html`, `solviro_energy_product_catalogue.pdf`, `CNAME`, `.nojekyll`, `README.md`) to the `main` branch.

     - **Source**: Deploy from a branch (`main` / root).

     - Check **Enforce HTTPS**.
   - Your website will immediately go live worldwide at https://solviroenergy.in!
